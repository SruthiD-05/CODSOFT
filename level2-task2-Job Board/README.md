# Job Board Website

This project is a **Job Board Website** created using **HTML, CSS, and JavaScript** as part of the **CodSoft Web Development Internship (Level 2 Task)**.

## Overview

The job board allows users to browse available job listings, search for jobs, and add new job postings.

## Features

* Job listing display
* Search functionality
* Add new job postings
* Dynamic job cards using JavaScript
* Clean and modern interface

## Technologies Used

* HTML
* CSS
* JavaScript

## Purpose

This project demonstrates building a dynamic interface where users can interact with job listings.
