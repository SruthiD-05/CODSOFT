# Calculator Web App

This project is a simple **web-based calculator** developed using **HTML, CSS, and JavaScript** as part of the **CodSoft Web Development Internship (Level 1 Task 3)**.

## Overview

The calculator allows users to perform basic arithmetic operations through an interactive interface.

## Features

* Addition
* Subtraction
* Multiplication
* Division
* Percentage calculation
* Decimal support
* Backspace functionality
* Clear display button

## Technologies Used

* HTML
* CSS
* JavaScript

## Purpose

The purpose of this project is to practice JavaScript logic and create an interactive front-end application.
