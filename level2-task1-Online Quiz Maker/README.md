# Online Quiz Maker

This project is an **interactive quiz application** developed using **HTML, CSS, and JavaScript** as part of the **CodSoft Web Development Internship (Level 2 Task)**.

## Overview

The application allows users to answer multiple-choice questions and receive their score at the end of the quiz.

## Features

* Multiple choice questions
* Interactive answer selection
* Score calculation
* Restart quiz option
* User-friendly interface

## Technologies Used

* HTML
* CSS
* JavaScript

## Purpose

The goal of this project is to implement JavaScript logic and create an interactive quiz experience.
